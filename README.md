# ShuttleIQ — public pages

Privacy policy, terms of use and support pages for **ShuttleIQ: Beep Test** (iPhone, iPad and Apple Watch), in US English.

Published with GitHub Pages: https://szymdzie.github.io/shuttleiq/

| Page | URL |
|---|---|
| Privacy Policy | https://szymdzie.github.io/shuttleiq/privacy/ |
| Terms of Use | https://szymdzie.github.io/shuttleiq/terms/ |
| Support | https://szymdzie.github.io/shuttleiq/support/ |

The app is English-only. The former Polish pages under `/pl/` redirect to the English ones.

## Editing

1. Edit the page bodies in `src/en`, and update the “Last updated” date when the privacy policy or the terms change.
2. Run `python3 build.py`. It writes the `index.html` files; they are committed, because GitHub Pages serves the repository root as is.
3. Commit and push. The commit history is the public record of earlier policy versions.

The Figtree font is self-hosted, so the pages make no third-party requests. It is licensed under the SIL Open Font License (`assets/fonts/OFL.txt`).
